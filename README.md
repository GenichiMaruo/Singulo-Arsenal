# Singulo Arsenal

[Singulo](https://github.com/GenichiMaruo/Singulo) の公式武器・防具アドオン。
本体の素材、失われた文明、触媒工学・重力技術の世界観を引き継ぎます。
**0.1.0 開発版**では、4段階・16部位の防具と、クリエイティブ専用の「シエル式試作レールガン」を追加しています。

## 対応環境

| Minecraft | ローダー | 状態 |
| --- | --- | --- |
| 1.21.1 | NeoForge (`N`) | このブランチの実装対象 |
| 1.20.1 | NeoForge (`N`) / Forge (`F`) | 将来対応方針。未実装 |

Java 21 **JDK**、NeoForge 21.1.256 を使用します。MOD ID は `singulo_arsenal`。
Singulo は必須で、本体 `1.21.1` ブランチのバージョンに合わせ暫定で `[0.10.0,0.11.0)` に対応します。
メインブランチは `1.21.1`、初期開発ブランチは `feature/0.1.0` です。

## シエル式試作レールガン

射撃型アンドロイドの白い外装・上下レール・3連コイルを受け継いだ、プレイヤー用の立体武器です。
クリエイティブタブから入手し、**メインハンドで右クリックを1.6秒長押し → 離して発射**。
32ダメージ、射程96ブロック、最大4体を貫通し、冷却は1.2秒。固体の壁で止まり、ブロックは壊しません。
現時点ではレシピ・弾薬・FE消費はありません。サバイバルでは発射できません。

コイルの回転、レールの開閉、発光する芯、集束リング、残光と着弾衝撃輪を専用メッシュで描画します。
充電音・発射音、照準の充電表示、軽い反動も含みます。詳しくは [レールガン仕様](docs/railgun.md)。

## 防具の進行

| セット | 本体の段階 | 解禁素材 | 中心機能 |
| --- | --- | --- | --- |
| 遺構探索装備 | 1 | 鋼板・ホワイトセラミック複合材 | 暗視、凍結防止、粉雪歩行、落下距離軽減 |
| 触媒循環装甲 | 2 | 超伝導コイル・ミュオン束 | 非戦闘時の自己修復、炎上時間短縮 |
| 慣性制御装甲 | 3 | 量子演算モジュール・量子もつれ素子 | 衝撃回収、過負荷、地上回避 |
| 事象境界装甲 | 5 | 重力場安定化ユニット・H凝縮体・縮退物質殻 | 手動の吸収防壁 |

探索装備と触媒循環装甲は作業台で独立して作れます。
慣性・事象境界装甲は、鍛冶台の「改修キット＋前段階の同じ部位＋追加素材」で改修します。
改修は名前・エンチャント・耐久の損耗値を維持し、電力・触媒残量・衝撃・防壁・装備内の待機時刻をリセットします。
レシピブック用の解禁進捗、専用クリエイティブタブ、日本語・英語の説明を含みます。

部位別の効果・消費量・製作方法は [防具仕様](docs/armor.md) を参照してください。
テクスチャは各段階を色分けした初期版のピクセルアートです。

## 操作・補給

- **V**：遺構探査面の暗視（10秒、再使用30秒）。
- **Z**：姿勢制御装甲の地上回避（衝撃20＋脚の2,000 FE、再使用1.5秒）。
- **B**：事象境界装甲の防壁（16ダメージ分、3秒、再使用60秒）。

設定のキー割り当てから変更できます。本体の G/H キーとは重複させていません。
対応するヘルメットを装備すると、補修残量・衝撃・過負荷・防壁状態を HUD に表示します。

慣性／事象境界の各部位は標準 FE アイテム能力で充電できます。
手に持ち、**スニークして電源ブロックの出力面を右クリック**すると最大20,000 FEずつ充電します。
回避は脚、落下軽減は靴、慣性ノックバック軽減と防壁は胴の電力を使います。

触媒循環装甲は、持ち物の「循環カートリッジ」を自動で使用します。
カートリッジは本体の「失活したミュオン触媒＋ホワイトセラミック複合材＋鋼板」から製作でき、1個で256点を補修します。
体力は回復しません。補給切れでも通常の防具として使えます。

## ビルド・検証

```sh
./gradlew --no-daemon build
```

Windows は `gradlew.bat build`。`build` の検査には Python 3 も必要です。
出力は `build/libs/Singulo-Arsenal-0.1.0-1.21.1N.jar` です。
命名規則は `<MOD名>-<MODバージョン>-<Minecraftバージョン><ローダー記号>.jar`。
1.21.1 に Forge 成果物は生成しません。バージョンは `gradle.properties` で管理します。

```sh
# ゲームなしで実行可能：能力計算の702チェック、レシピ・翻訳・モデル・再生成検査
python3 tools/check.py
# 本体の素材IDも照合する場合
SINGULO_SOURCE=/absolute/path/to/Singulo python3 tools/check.py
# 本体と同時ロードする実際の GameTest（16テスト）
./gradlew runGameTestServer -PsinguloJar=/absolute/path/Singulo-0.10.0-1.21.1N.jar
```

CI はビルドとオフライン検査に加え、固定した本体コミットを別途ビルドして GameTest を実行します。
GameTest は、電力能力、保存・読み込み、触媒消費、補修拡張、防壁、回避条件、落下、鍛冶更新を検証します。
レールガンでは充電・冷却、クリエイティブ制限、貫通順序、壁の遮蔽、味方の除外、離して発射する処理も検証します。
テストクラスとテスト用構造物は配布 JAR から除外します。

## 開発起動

同じ Minecraft・ローダーに対応する Singulo 本体 JAR を用意してください。
本体を Arsenal の JAR に同梱・再配布しません。

```sh
./gradlew runClient -PsinguloJar=/absolute/path/Singulo-0.10.0-1.21.1N.jar
./gradlew runServer -PsinguloJar=/absolute/path/Singulo-0.10.0-1.21.1N.jar
```

専用サーバーは Minecraft EULA を確認し、同意する場合にのみ `run/eula.txt` を設定して再実行してください。
クライアント起動には画面表示環境が必要です。
`singuloJar` 未指定・ファイル不存在は明示的にエラーにします。
起動ログの `Singulo Arsenal initialized`、MOD 一覧、本体と同時ロードできることを確認してください。

リソースの再生成は `python3 tools/generate_resources.py`。外部 Python パッケージは不要です。
