# 防具仕様（0.1.0 開発版）

防御値の並びは頭／胴／脚／足です。各部位は単品でも機能し、指定された組み合わせで能力が拡張します。
本体の素材IDは `tools/check.py` に `SINGULO_SOURCE` を渡して照合できます。

## 遺構探索装備：本体段階1

防御値 2/6/5/2（鉄相当）。耐久倍率18、修理素材は `singulo:steel_plate`。
作業台で鋼板とホワイトセラミック複合材から作れます。

| 部位 | 名前 | 効果 |
| --- | --- | --- |
| 頭 | 遺構探査面 | 暗視キー V：10秒の暗視、再使用30秒 |
| 胴 | 補強探索服 | 鉄相当の防御と、鉄防具より高い耐久 |
| 脚 | 踏破用作業衣 | バニラの凍結防止装備タグで凍結蓄積を防ぐ |
| 足 | 緩衝作業靴 | 粉雪歩行。落下判定の距離を3ブロック分減らす |

電力・触媒は不要です。探索用として上位装備と混成できます。

## 触媒循環装甲：本体段階2

防御値 3/8/6/3（ダイヤ相当）、防具強度2。耐久倍率33。
超伝導コイルとミュオン束から作業台で製作。修理素材は `singulo:superconducting_coil`。

| 部位 | 名前 | 効果 |
| --- | --- | --- |
| 頭 | 循環監視面 | 対応する胴の補修残量を HUD に表示 |
| 胴 | 触媒循環装甲 | 非戦闘10秒後から1秒につき自身の耐久を1回復 |
| 脚 | 補助循環装甲 | 胴の補修を、装備中の触媒循環防具全体に拡張 |
| 足 | 耐熱作業靴 | 溶岩の外で残り炎上時間を最大2秒に制限 |

補修量は装備全体で毎秒1点。胴→頭→脚→足の優先順です。
被弾時と、自分の攻撃で相手にダメージを与えた時に非戦闘時間を数え直します。
補修可能な損傷がある場合だけ、持ち物の循環カートリッジを1個使い、256点を補充します。
カートリッジの素材は、失活したミュオン触媒・ホワイトセラミック複合材・鋼板を各1個。
体力回復、上位セットの自動修復、溶岩無効化はありません。

## 慣性制御装甲：本体段階3

防御値 3/8/6/3、防具強度2。耐久倍率37。各部位100,000 FE。
触媒循環装甲を鍛冶台で改修します。各部位で改修キット1個と量子演算モジュール1個を使用。
キットは超伝導コイル2・量子演算モジュール2・量子もつれ素子1。修理素材は量子演算モジュール。

| 部位 | 名前 | 効果 |
| --- | --- | --- |
| 頭 | 慣性観測器 | 蓄積衝撃・過負荷・蓄積装備の FE を HUD に表示 |
| 胴 | 慣性制御装甲 | 100 FE/回でノックバック60%軽減。衝撃上限100 |
| 脚 | 姿勢制御装甲 | Zで地上回避。衝撃20＋脚の2,000 FE、再使用1.5秒。単品の衝撃上限40 |
| 足 | 衝撃回収靴 | 200 FE/回で3ブロック超の落下ダメージを50%軽減。6ブロック以上なら衝撃回収 |

胴を装備している場合は胴の衝撃を、胴がない場合は脚の衝撃を回避に使います。
他者から実際に受けたダメージ1点につき衝撃2、1被弾最大20。環境ダメージ・直接の自傷では回収しません。
落下からの回収は `距離−5`、1落下最大10。回収は1秒に1回、蓄積は装備中毎秒1ずつ減衰します。
満杯になると衝撃を放出して0に戻り、5秒間の過負荷になります。
過負荷中は該当装備の衝撃回収・回避・胴のノックバック軽減が停止します。
足だけの装備では靴に衝撃を保存しますが、回避には胴または脚の蓄積が必要です。

回避は視線の水平方向に進みます。空中・搭乗中・水中・滑空中は使用できず、無敵時間も付与しません。
落下・被弾で衝撃を貯めても電力は増えません。

## 事象境界装甲：本体段階5

防御値 3/8/6/3、防具強度3（ネザライト相当）。耐久倍率40。各部位500,000 FE。
慣性制御装甲を鍛冶台で改修します。各部位で改修キット1個と重力場安定化ユニット1個を使用。
キットは縮退物質殻2・重力場安定化ユニット2・H凝縮体1。修理素材は重力場安定化ユニット。

| 部位 | 名前 | 効果 |
| --- | --- | --- |
| 頭 | 境界観測面 | 胴の FE・防壁残量・持続時間・再使用待ちを HUD に表示 |
| 胴 | 事象境界装甲 | Bで防壁展開：初期20,000 FE、維持100 FE/t、吸収量16点、持続3秒 |
| 脚 | 境界安定装甲 | 展開時に装備していれば防壁の持続が5秒になる |
| 足 | 空間固定靴 | 対応する胴の防壁作動中、落下ダメージとノックバックを75%軽減 |

再使用は展開から60秒。防壁は防御・ポーションによる軽減後、バニラの追加体力より前に処理します。
吸収可能量を超えた分は通常どおり受けます。端数ダメージの消費は切り上げです。
電力不足・時間切れ・吸収残量切れで停止。装備を外しても待機時間は消えません。
奈落・`/kill` など、無敵を貫通するダメージは防ぎません。
致命傷の自動回避や常時無敵は実装していません。

## 状態の保存と改修

電力・衝撃・補修残量・防壁・装備内の待機時刻はデータコンポーネントに保存し、装備とともに同期します。
同じ種類の装備への交換による連続発動を防ぐため、プレイヤーの再使用待ちも併用します。
装備の改修では名前・エンチャント・耐久の損耗値を維持し、内部資源と装備内待機時刻を0にします。
慣性から境界への改修で、回避など旧セットの能力を引き継ぐことはありません。

## 検証

`./gradlew build` はコンパイル・JAR生成とオフライン検査を実行します。
`python3 tools/check.py` は能力計算702チェックとレシピ・翻訳・PNG・生成の再現性を検査します。

実際の本体JARを使用する `runGameTestServer` には10個の統合テストがあります。
FEの上限とシミュレーション、保存・読み込み、補修の消費と戦闘待ち、脚による補修拡張、
防壁の起動費用と連打拒否、不正な操作、空中回避拒否と地上回避の消費、
鍛冶による名前・エンチャント保持と資源初期化、防壁の超過ダメージ・奈落、落下の費用を対象とします。
GameTestの実行と、クライアントでの見た目・キー操作確認は、オフライン検査とは別の検証です。
