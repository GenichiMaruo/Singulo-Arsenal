## どんな mod？

Singulo Arsenal は、[Singulo](https://github.com/GenichiMaruo/Singulo) の工場で作った素材から**防具・武器・工具**を作るアドオンです。
どの装備も、本体で扱う物理現象をひとつ題材にしています。超伝導の防護服は磁場を押し出して宙に浮き、縮退圧の鎧は受けた衝撃を圧力として溜め、コラプサー装甲は背中のブラックホールと核パスタの相で性質が変わります。

物理を題材にしていますが、数値や挙動はゲーム用に調整しています。

## 必要な環境と導入

- Minecraft **1.21.1**、NeoForge **21.1.256 以上**、Java 21。
- Singulo **0.16 系**が必須です。Singulo Arsenal の JAR と一緒に `mods/` に入れます。
- マルチプレイではクライアントとサーバーの両方に導入します。
- 日本語と英語に対応しています。ほかの言語を選んだ場合は英語で表示します。

## 装備の段階

装備は本体の技術段階に合わせて3つの段階に分かれます。上の段階ほど強く、作るのに要る本体の設備も増えます。

| 段階 | 防具 | 武器 | 工具（0.2.0） |
| --- | --- | --- | --- |
| 2（極低温） | マイスナー防護服 | クエンチ・セイバー | SQUID探査ピック |
| 4（時間） | 縮退圧装甲 | カシミール刃 | 縮退圧ブレーカー、剪断ソー |
| 5（特異点、Jet Forge） | コラプサー装甲 | 潮汐断裁刃、降着ジェット砲 | 降着ドリル |

レシピの形は完成品の図になっていて、その部位で働く部品がその位置に入ります。材料と配置は[装備仕様のレシピ](../arsenal.md#レシピ)を、ゲーム内では JEI を見てください。
クリエイティブモードでは、専用タブから充電済みの装備を取り出せます。

## 電力

- 装備はすべて標準の FE で動きます。装備を手に持ち、**スニークして電源の出力面を右クリック**すると、容量の 1/8 ずつ充電します。
- 装備から FE を取り出すことはできません。機械の電池にはなりません。
- 武器・工具の残量はアイテム欄のバー、防具の残量は HUD とツールチップで確認できます。
- **降着**：着ているコラプサー装甲と、手に持っている潮汐断裁刃・降着ジェット砲・降着ドリルは、持ち物の質量ペレットを1個 500,000 FE の電力に変えます。タンクに丸ごと入るときだけ、装備ごとに毎秒1個まで使います。
- **質量ペレット缶**（0.2.0）：ペレットを 4,096 個まで入れて持ち歩けます。降着は缶の中身から先に使うので、持ち物のペレットはクラフト用に残せます。
  - 右クリックで持ち物のペレットをすべて収納、スニーク＋右クリックで 1 スタック取り出します。
  - 持ち物画面では、ペレットを缶の上に置くと入り、空の手で缶を右クリックすると取り出せます。

## 防具

### マイスナー防護服（段階2）

超伝導体の磁場排除と磁束ピン止めが題材です。

- **観測帽**：近くの敵対的なものを壁越しに表示します。
- **胸殻**：飛んでくる矢などを跳ね返します。
- **脚衣**：着ている部位の電力を損失なく均等にし、少し速く歩けます。
- **浮上靴**：空中でスニークすると、磁束ピン止めでゆっくり降下し、落下ダメージを受けません。
- **全身**：殴ってきた相手を弾き飛ばします。

### 縮退圧装甲（段階4）

押しても縮まず、限界を超えると一気に崩れる縮退圧が題材です。

- **胸甲**：大きな一撃を圧力に変えて受け止めます。圧力が限界に達すると装甲が崩壊して周囲を吹き飛ばし、しばらくこの機能が止まります。
- **起動機能（V キー）**：限界の前に、溜めた圧力を自分で衝撃波として放出します。
- **兜**は毒とウィザーを濾過し、**脚甲**は接地中のスニークで踏ん張ってダメージとノックバックを減らし、**鉄靴**は高所からの落下を衝撃波に変えます。

### コラプサー装甲（段階5）

背中に封じ込めたブラックホールを背負う最上位の装甲です。

- **核パスタの裏地**：受けた衝撃で、ニョッキ相（速い）→スパゲッティ相（間合いが伸びる）→ラザニア相（硬いが遅い）と相が移ります。今の相は HUD と胸の模様で分かります。
- **電力シールド**：一式を着ると、被ダメージを電力で肩代わりします（消費は激しめ）。
- **事象の地平面**：致死の一撃を受けると一度だけ踏みとどまり、短い無敵と周囲への反撃が起きます。再使用まで10分です。
- **ジェット噴射（V キー、噴流靴が必要）**：視線方向へ急加速し、背後を焼きます。溜まった負荷を減らせます。
- **観測冠**は有害な効果をすべて消し、**噴流靴**で落下ダメージがなくなります。

## 武器

- **クエンチ・セイバー**（段階2）：当てるたびに電流が溜まり、5発目で超伝導が破れて周囲を焼きます。
- **カシミール刃**（段階4）：防具の一部を常に無視します。右クリック長押しで鏡を閉じると、次の一撃が防具を完全に無視して強くなります。
- **潮汐断裁刃**（段階5）：当てた相手に潮汐応力が溜まり、引き伸ばされて見えます。右クリック長押しでロッシュ焦点のブラックホールを出して周りの敵を引き寄せ、離すと応力に応じて断ち切ります。
- **降着ジェット砲**（段階5）：肩に構える銃型の兵器です。
  - **左クリック1回で1発**。チャージのあとジェットを 2 秒間噴き出し、前方の敵を貫きます。4発撃つと自動でリロードします。
  - **右クリック**で地形保護と地形破壊を切り替えます。破壊モードでは、発射の瞬間に一定の深さまでトンネルを掘ります。

味方、同じチーム、PvP が無効なプレイヤー、防具立ては、どの武器・能力の対象にもなりません。

## 工具（0.2.0）

電力で動き、耐久値はありません。電力が切れると素手と同じ速さになります。エンチャントも使えます。

- **SQUID探査ピック**：右クリックで周囲の鉱石を壁越しに10秒表示します。映る鉱石は本体のニュートリノ・スキャナーと同じ感度で決まり、本体の**ニュートリノ感度モジュール**を持って、もう片方の手にピックを持って使うと感度が上がります。感度を上げたスキャナーから作ると、その感度を引き継ぎます。
- **縮退圧ブレーカー**：ツルハシとシャベルを兼ね、3×3 をまとめて掘ります。
- **剪断ソー**：葉のついた木を丸ごと切り倒します。葉のない丸太の建物は巻き込みません。
- **降着ドリル**：すべての工具を兼ね、ドロップと経験値を持ち物へ直接送ります。右クリックで単体／3×3／鉱脈を切り替えます。

範囲採掘はスニーク中は1ブロックだけになります。チェストや機械、Singulo のブロック、極端に硬いブロックは巻き込みません。

## モジュール（0.2.0）

**モジュール統合台**で、装備に拡張モジュールを組み込めます。統合台に電力を入れ、中央に装備を置き、周りのソケットにモジュールを並べて「統合」を押します。空にして統合すれば外せます。
ソケットの数は装備の段階で決まります（段階2は1個、段階4は3個、段階5は5個）。モジュールは本体の精密組立台で作ります。

| モジュール | 入る装備 | 効果 |
| --- | --- | --- |
| ビットドローン | 胴 | 背後に浮かぶビットが敵を自動で撃つ |
| 拡張コンデンサ | すべて | 電力容量を増やす |
| 追加装甲板 | 防具 | 防御力と防具強度を上げる |
| 慣性スラスター | 靴 | ジャンプ力と段差の乗り越えを強化 |
| メトリックドライブ | 防具 | 電力だけで飛べる |
| 誘導給電コイル | 胴 | 胴の電力を持ち物の FE 機器へ分ける。他 mod の機器も対象 |
| 重力集積 | 防具 | 周りのアイテムと経験値を引き寄せる。スニーク中は止まる |
| 冷却モジュール | 武器 | 再使用時間を短くする |
| 出力増幅器 | 武器 | ダメージを上げる |
| 融解起爆 | 降着ジェット砲 | 着弾点が大爆発する |
| 掘削オーバークロック | 工具 | 採掘速度を上げる |
| 熔融精錬 | 工具 | 鉱石と原石を精錬済みで落とす |

多くは重ねて入れると効果が増えます。効果量と材料は[装備仕様のモジュール統合台](../arsenal.md#モジュール統合台)を見てください。

## 操作の一覧

| 操作 | 内容 |
| --- | --- |
| V キー（変更可） | 縮退圧の圧力放出、コラプサーのジェット噴射 |
| 空中でスニーク | マイスナー浮上靴でゆっくり降下 |
| 右クリック長押し | カシミール刃の鏡閉じ、潮汐断裁刃のロッシュ焦点 |
| 左クリック | 降着ジェット砲の発射 |
| 右クリック | ジェット砲の地形モード切替、ピックの鉱石探査、ドリルの採掘モード切替、ペレット缶の収納 |
| スニーク＋電源を右クリック | 装備の充電 |
| Shift を押しながらツールチップ | 装備の詳しい説明 |
