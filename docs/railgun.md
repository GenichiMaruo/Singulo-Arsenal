# シエル式試作レールガン

Minecraft 1.21.1 / NeoForge用のクリエイティブ専用試作兵装。
Singulo本体の射撃型アンドロイドの銃を基に、白い外装、黒い上下レール、3連の角形コイル、開放型ストック、水緑の発光芯をプレイヤー用の立体モデルにしています。

## 入手・操作

Singulo Arsenalのクリエイティブタブ、または以下のコマンドで入手できます。

```mcfunction
/give @s singulo_arsenal:ciel_railgun
```

メインハンドに持って右クリック（「アイテムの使用」）を長押しします。
1.6秒で充電が完了し、照準下の表示と完了音で知らせます。離すと発射。
途中で離すと放電して終了し、発射しません。射撃後は1.2秒の冷却が必要です。
右利き・左利き、一人称・三人称に対応しています。

| 項目 | 現在の値 |
| --- | --- |
| 基礎ダメージ | 32（防御による軽減前） |
| 射程 | 96ブロック |
| 貫通 | 照準線に近い位置から最大4体 |
| 障害物 | 固体の当たり判定で止まる。ガラスも貫通しない |
| ブロック破壊 | なし |
| 味方 | スコアボードの同チームは対象外。プレイヤー間の攻撃制限も適用 |
| レシピ・弾薬・FE | 未導入 |
| 使用モード | クリエイティブのみ。オフハンドでは使用不可 |

## 演出

- 充電に応じて上下レールが開き、3連コイルが交互に回転。銃口の集束リングと照準の8段階表示が充電を伝えます。
- 発射光は白い芯・水緑の光・外側の薄い光の3層。螺旋状の残光と加速リングが射線に沿って走ります。
- 着弾点では壁面の向きに沿って2重の衝撃輪が広がり、光が短時間で減衰します。
- 専用の充電ループ音・充電完了音・電磁射撃音・中断時の放電音。字幕は日本語・英語を用意しています。
- 一人称では軽い銃の後退、跳ね上がり、視野角の変化があります。

光線・リング・銃本体は実際の頂点から描画します。パーティクルは使用しません。
加算合成と深度判定を使い、光が手前の壁を突き抜けて表示されるのを防ぎます。
外部の描画Mod・シェーダーパックとの組み合わせは未検証です。

照準・ダメージ・遮蔽・冷却はサーバーで判定し、確定した射線を周辺プレイヤーへ送ります。
クライアントからダメージ値や着弾点を指定する仕組みはありません。

## 開発者向けの確認

`runGameTestServer`は本体Modと一緒に読み込み、実エンティティに対する射撃を検証します。
実クライアントの描画確認は、GameTestが保存した使い捨てワールドをコピーして実行します。
通常のビルドには画面確認用コードを含めません。

```sh
python3 tools/review/prepare_gui.py
./gradlew -I tools/review/gui.gradle runClient -PsinguloJar=/absolute/path/Singulo-0.10.0-1.21.1N.jar
```

画面表示環境が必要です。`build/gui-review/screenshots/`に構え・充電・発射・着弾・左利き・三人称の画像を保存します。
画面確認後、配布用は初期化スクリプトなしで`./gradlew clean build`を実行してください。

モデル・翻訳の再生成は`python3 tools/generate_resources.py`。
独自に合成した音声を再生成する場合は`python3 tools/generate_railgun_resources.py --sounds`（ffmpegが必要）。
音声ファイルは同梱済みなので、通常のビルドやリソース検査にffmpegは不要です。
