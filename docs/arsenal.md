# 装備仕様（0.1.0 Beta）

対象は Singulo 0.16.0 / Minecraft 1.21.1 / NeoForge です。数値の正本は `core/Rules.java` で、この文書はそこから書き起こしています。
防御値の並びは頭／胴／脚／足です。

## 設計の方針

- 1セット・1武器につき、本体で扱う物理現象をひとつ題材にし、性能と形の両方に出す。
- 武器・防具の性能は、作るのに要る本体の設備に見合わせる。Jet Forge の素材を要しない装備が、コラプサー級を上回らないようにする。
- 本体の電力経済を壊さない。装備は FE を受け取るだけで、機械の電源にはならない。
- レシピの形は完成品の図にする。素材は「その部位で実際に働く部品」を、その部位の位置に置く。

### マイスナー防護服（段階2）

超伝導体は磁場を押し出し、磁束は格子にピン止めされます。白いセラミックの外装に、冷たい電流の輪が触れずに浮かびます。

| 部位 | 機能 |
| --- | --- |
| 観測帽 | SQUID 磁力計：24ブロック内の敵対的なものを壁越しに表示 |
| 胸殻 | 飛び道具を反発（1,500 FE／発、間隔0.2秒） |
| 脚衣 | 永久電流：着用部位の電力を各部位の容量内で損失なく均等化。拡張コンデンサによる容量差にも対応。歩行速度 +7% |
| 浮上靴 | 空中でスニーク：磁束ピン止めで毎秒1ブロック降下（10 tickごとに300 FE）。残量が300 FE未満なら全量を消費し、電力が尽きると終了。落下距離はリセット |
| 全身 | レンツの法則：近接攻撃者を弾き飛ばす（800 FE） |

降下を止めないのは磁束クリープの再現で、同時にサーバーの飛行判定による切断を避けるためです。

### 縮退圧装甲（段階4）

縮退圧は押しても縮まず、限界を超えると一気に崩れます。板を重ねた鎧で、圧力が上がるほど継ぎ目の光が強まります。

| 部位 | 機能 |
| --- | --- |
| 兜 | 毒とウィザーを濾過（2,000 FE） |
| 胸甲 | チャンドラセカール限界：1撃の最終ダメージが8を超える分を圧力へ変換（4,000 FE／点）。圧力は毎秒1減衰。圧力60で崩壊：半径6の衝撃波を出し、30秒間この機能が止まる |
| 脚甲 | 接地中のスニークで踏ん張る：被ダメージ -30%、ノックバック無効 |
| 鉄靴 | 4ブロック以上の落下を衝撃波に変換（500 FE／ブロック、落下ダメージ無効） |

起動機能（V）は、圧力15以上で崩壊の前に手動で放出します。ロックはかかりません。

### コラプサー装甲（段階5・Jet Forge）

光を吸う地金と象牙色の縁取り。背中には封じ込めたブラックホールと回転する降着円盤を背負い、胸の中央にも小さなブラックホールが収まります。

| 部位 | 機能 |
| --- | --- |
| 観測冠 | 無毛定理：有害な効果をすべて消去（10,000 FE、毎秒） |
| 炉心甲＋潮汐脚甲 | 核パスタの裏地：受けた衝撃で相転移（負荷は毎秒1減衰） |
| 噴流靴 | 落下ダメージ無効。炉心甲と合わせてジェット噴射 |
| 全身 | 電力シールド：防具で軽減した後の被ダメージを、1あたり 200,000 FE で肩代わり（頭・靴・脚・胴の順に消費）。事象の地平面が使えるときは、胴に発動分の 8,000,000 FE を残す |
| 全身 | 事象の地平面：致死の一撃を止め、体力40%で3秒間無敵、半径9に60ダメージ（8,000,000 FE、再使用10分） |

本体の核パスタ積層蓄電庫と同じ3相です。胸の裏地の模様で今の相が見えます。

| 負荷 | 相 | 効果 | 裏地の見た目 |
| --- | --- | --- | --- |
| 0–33 | ニョッキ | 速度 +15% | 粒 |
| 34–66 | スパゲッティ | 間合い +1、ノックバック耐性 +0.5 | 糸 |
| 67–100 | ラザニア | 被ダメージ -30%、速度 -10% | 板 |

**ジェット噴射**（V）：視線方向へ急加速し、背後10ブロックを24ダメージで焼きます。200,000 FE と負荷25を消費、再使用1.5秒。
重い相で溜まった負荷を、機動力に変えて捨てる行動になっています。

## 武器

| 武器 | 段階 | ダメージ／速度 | 電力 |
| --- | --- | --- | --- |
| クエンチ・セイバー | 2 | 9 / 1.6 | 240,000 FE |
| カシミール刃 | 4 | 13 / 1.6 | 1,000,000 FE |
| 潮汐断裁刃 | 5 | 22 / 1.0 | 8,000,000 FE |
| 降着ジェット砲 | 5 | 射撃のみ | 16,000,000 FE |

- **クエンチ・セイバー**：命中で電流が溜まり、5発目で超伝導が破れて周囲半径4.5に10ダメージと炎上（8,000 FE、再使用3秒）。
- **カシミール刃**：2枚の鏡の間の真空が刃です。常に防具の効果を35%無視。使用長押し0.8秒で鏡が閉じ（40,000 FE、再使用8秒）、6秒以内の次の一撃は防具を完全に無視して1.5倍になります。
- **潮汐断裁刃**：命中で潮汐応力を付与（最大5、被ダメージ +8%／層、6秒）。使用長押しでロッシュ焦点が半径12の敵を引き寄せ（300,000 FE/秒）、離すと応力に応じて16〜66ダメージで断裁し、応力を解放します（再使用5秒）。応力を受けた体は実際に引き伸ばされて描画され、応力が切れると2.5秒かけて元に戻ります。ロッシュ焦点のブラックホールは本体と同じ重力レンズで背景を歪め、自分にも他のプレイヤーにも同じように見えます。刃に封じたブラックホールは両面の窓から見え、他のプレイヤーからは周囲もわずかに歪んで見えます。体力200以上の相手は引き寄せが弱まります。
- **降着ジェット砲**：肩付けで構える銃型の兵器です。後極を磁気ミラーで塞いであるので、ジェットは銃身からのみ出ます。ビームは本体の Jet Forge と同じシェーダーで描きます。
  - **左クリック1回で1発**です。リングが1.4秒チャージしてから一度だけ発射され、ジェットは全長で2秒間出続けます。前方80ブロックを貫通して 56 DPS（防具の6割を無視）、1発 1,000,000 FE。押し続けても連射しません。
  - **弾倉は4発**で、撃ち切ると自動で8秒のリロードに入り、排熱板が開いて、マガジンを外して新しいものを入れ、コッキングハンドルを引きます。
  - ジェットの音はビームの聞き手に一番近い位置から鳴り、ジェットが消えると同時に止まります。
  - **右クリック**で地形保護と地形破壊を切り替えます（初期は保護）。破壊モードは**発射の瞬間に**半径1.75のトンネルを最初の面から20ブロックの深さまで一度に貫き、その後の照射はブロックを壊しません。融けたブロックはドロップしません。ブロックエンティティ、Singulo のブロック、硬度50を超えるもの、スポーン保護や保護 MOD で禁止された場所は壊さず、そこでトンネルは止まります。

味方・同じチーム・クリエイティブや PvP 無効のプレイヤー・防具立ては、全武器・全機能の対象外です。
ジェットは発射起点に重なる近距離の敵にも命中します。カシミール刃の強化された一撃は、その刃による近接攻撃で消費します。

## 工具

電力で動き、耐久値はありません。電力が切れると素手の速度になります。エンチャントと統合台のモジュールが使えます（拡張コンデンサ、掘削オーバークロック）。

| 工具 | 段階 | 採掘速度 | 電力 | 消費 |
| --- | --- | --- | --- | --- |
| SQUID探査ピック | 2 | 10（ダイヤモンド級まで） | 240,000 FE | 150 FE／ブロック |
| 縮退圧ブレーカー | 4 | 16 | 2,000,000 FE | 1,000 FE／ブロック |
| 剪断ソー | 4 | 16 | 2,000,000 FE | 800 FE／ブロック |
| 降着ドリル | 5 | 40 | 16,000,000 FE | 2,500 FE／ブロック |

- **SQUID探査ピック**：右クリックで半径16の鉱石を壁越しに10秒表示します（20,000 FE、再使用3秒、近い順に最大256個）。
- **縮退圧ブレーカー**：ツルハシとシャベルを兼ね、掘った面の3×3をまとめて壊します。スニーク中は1ブロック。
- **剪断ソー**：斧として使います。自然の葉がついた木の幹を丸ごと切り倒します（最大256本）。スニーク中は1本。葉のない丸太の建物は巻き込みません。
- **降着ドリル**：全ツールを兼ね、ドロップと経験値を持ち物へ直接送ります。右クリックで単体／3×3／鉱脈（同じ鉱石を最大64個）を切り替えます。持ち物の質量ペレットで自動充電します。

範囲採掘は、ブロックエンティティ、Singulo のブロック、叩いたブロックより極端に硬いブロックを巻き込みません。保護 MOD で禁止された場所も壊しません。

## モジュール統合台

専用の機械「モジュール統合台」で、装備に拡張モジュールを組み込みます。電力は標準 FE で受け取り、統合1回に 5 秒・200,000 FE を使います。
受け取った電力はワールドに保存され、チャンクの再読み込み後も保持します。

1. 中央の台に装備を置きます。組み込み済みのモジュールは周囲のソケットに取り出されます。
2. ソケットのモジュールを入れ替えて「統合」を押します。空にして統合すれば、モジュールを外せます。

| 装備の段階 | ソケット数 |
| --- | --- |
| 2 | 1 |
| 4 | 3 |
| 5 | 5 |

| モジュール | 対象 | 効果 |
| --- | --- | --- |
| ビットドローン | 胴 | ビット2機が体の後ろ上に扇状に浮かび（本人の1人称視点では非表示）、16ブロック内の敵を毎秒自動で撃つ（5ダメージ、1,500 FE／発） |
| 拡張コンデンサ | すべて | 電力容量 +50% |
| 追加装甲板 | 防具 | 防御力 +2、防具強度 +1 |
| 慣性スラスター | 靴 | ジャンプ力と段差の乗り越えを強化 |
| 冷却モジュール | 武器 | 再使用時間 -25%（重複可） |
| 出力増幅器 | 武器 | 装着した武器の近接攻撃・固有攻撃のダメージ +15%（重複可）。ドローンと防具の能力はそれぞれの基礎ダメージを使用 |

| メトリックドライブ | 防具 | エキゾチック物質なしで飛行できる。飛行中 400 FE/t、落下ダメージ無効 |
| 掘削オーバークロック | 工具 | 採掘速度 +40%（重複可） |
| 融解起爆 | 降着ジェット砲 | 発射と同時に着弾点が爆発（半径7、中心60〜端24ダメージ。2個目以降は半径+1.5）。地形破壊モードでは貫通した一番奥で爆発し、石類は溶岩とマグマに、その他のブロックは通常の爆発のように壊れる。保護モードでは地形を壊さない |

モジュールは精密組立台で作ります。ビットドローンの材料には、ビット型アンドロイドの小型クリスタルメモリが要ります。

## 降着

コラプサー級の装備（防具と潮汐断裁刃・降着ジェット砲）は、持ち物の質量ペレットを1個 500,000 FE で自動的に電力に変えます。タンクに丸ごと入るときだけ消費します。

### コラプサー一式の製作コスト

防具一式で積層板12枚、すなわち次の量になります（並列を使わない場合）。

- コラプサー・インゴット12・核パスタ12 → Jet Forge 計24回＋核パスタ12回
- ジェット凝縮体 48（ジェット・コレクター1基で約48分）、ネザライト12
- 電力 約10 TFE（Pリアクター最大出力 2.1 GFE/t で約4分）、液体ヘリウム 約60,000 mB

## 検証

- `tools/check.py`：計算チェック、レシピと本体の ID の照合、日英の翻訳キーと書式の一致、再生成の決定性。
- `runGameTestServer`：本体 JAR と同時ロードして42テスト。
- `tools/review`：実クライアントで全状態を撮影するハーネス。
