# Singulo Arsenal 0.3.2

Compatibility update for Singulo 0.21.0.

- Retains equipment behavior, balance, recipes, registry IDs and saved data from 0.3.1.
- Requires Singulo 0.19.0 or newer without an upper bound; the integration suite targets pinned 0.21.0 source. Future versions are not certified.
- Back up worlds before upgrading. Existing 0.3.0 cannon migration and downgrade limitations still apply.
- On Minecraft 1.20.1, external datapack item-tag elements using `singulo_arsenal:jet_lance` must use `singulo_arsenal:jet_cannon`; tag names and recipe IDs stay unchanged.
