# Singulo Arsenal 0.3.4

- Fixes a startup crash with Apothic Attributes on Minecraft 1.20.1 (armor mixin conflict with its armor penetration).
- Arsenal's block drop and mining experience hooks no longer prevent other mods from hooking the same calls.
- Retains equipment behavior, recipes, registry IDs, and saved data from 0.3.3.
- Requires Singulo 0.23.1 or later for Minecraft 1.20.1. Back up your world before upgrading.
