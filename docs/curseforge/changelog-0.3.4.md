# Singulo Arsenal 0.3.4

- Fixes a startup crash with Apothic Attributes on Minecraft 1.20.1 (armor mixin conflict with its armor penetration). Both mods' armor calculations now apply.
- Arsenal's block drop and mining experience hooks no longer prevent other mods from hooking the same calls.
- Retains equipment behavior, recipes, registry IDs, and saved data from 0.3.3.
- The declared minimum Singulo version remains 0.19.0. Back up your world before upgrading.
