# Singulo Arsenal 0.2.1 — Minecraft 1.21.1

Compatibility update. Requires the matching Singulo 0.16.x or 0.17.x build.

## English

- Allow Singulo 0.17.x; Arsenal 0.2.0 rejected 0.17.0 through its dependency upper bound.
- Pin integration validation to the released Singulo 0.17.0 commit. Equipment mechanics, recipes and saved item data are unchanged.

## 日本語

- Singulo 0.17.x に対応しました。Arsenal 0.2.0 では依存関係の上限により 0.17.0 が読み込めませんでした。
- 連携検証を公開済み Singulo 0.17.0 のコミットへ固定しました。装備の動作・レシピ・保存データの形式は変えていません。
