# Singulo Arsenal 0.2.0 — Minecraft 1.20.1 / NeoForge and Forge

Requires the matching Singulo 0.16.x build, NeoForge 47.1.106+ or Forge 47.4.26+, and Java 17. Install on both the client and server.
Ports the 0.2.0 features and fixes to Minecraft 1.20.1. Select the N file for NeoForge or the F file for Forge.

## English

- Added four FE-powered mining tools: the SQUID Pick, Degeneracy Breaker, Shear Saw and Accretion Drill, with ore scanning, area mining, tree felling and vein mining.
- Added metric drive, meltdown, overclock, smelter, induction and collector modules. Equipment now has 1, 3 or 5 module sockets depending on its tier.
- Added a mass pellet canister that stores up to 4,096 pellets and supplies accretion-powered equipment before loose pellets.
- Added a Collapsar suit energy shield, and reworked the Accretion Jet Cannon with a four-shot magazine, charge-up and terrain protection/breaking modes.
- Improved equipment models, drones, effects, sounds, the Module Integrator screen and tooltips. Expanded the Japanese and English guides.
- Fixed protected area mining, energy costs for canceled blocks, interrupted-shot reload bypasses, and lost smelting output above a stack limit.
- Added the Minecraft 1.20.1 shader blend configuration so the cannon's jet remains translucent and glows over the background.
- Existing Module Integrators retain their contents when upgrading from 0.1.0.

## 日本語

- 電力式工具4種（SQUID探査ピック、縮退圧ブレーカー、剪断ソー、降着ドリル）を追加。鉱石探査、範囲採掘、伐採、鉱脈採掘に対応しました。
- メトリックドライブ、融解起爆、オーバークロック、自動精錬、誘導給電、回収モジュールを追加。装備の段階に応じてモジュール枠が1／3／5個になりました。
- 質量ペレットを最大4,096個収納できるペレット缶を追加。降着装備は缶の中のペレットから優先して補給します。
- コラプサー装甲に電力シールドを追加。降着ジェット砲は4発マガジン、チャージ、地形保護／破壊モードに対応しました。
- 装備モデル、ドローン、エフェクト、音、統合台画面、ツールチップを改善し、日英ガイドを拡充しました。
- 採掘保護、キャンセルされたブロックへの電力消費、持ち替えによるリロード回避、精錬結果のスタック上限による消失を修正しました。
- 1.20.1用のシェーダー合成設定を追加し、ジェットが不透明な筒にならず、背景が透ける発光として描画されるよう修正しました。
- 0.1.0のモジュール統合台は内容を維持したまま移行できます。
